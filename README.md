# Diario de fierros

App web para llevar la cuenta de las series con mancuerna y pesas rusas. Elegís la pesa, después la técnica (con fotos de cómo se hace) y anotás las repeticiones de cada brazo. Cada serie queda en un calendario y los objetivos son semanales, de lunes a domingo.

## Instalarla en el iPhone

1. Abrí <https://fausto0718.github.io/diario-de-fierros_1/> en Safari.
2. Tocá Compartir y después "Agregar a Inicio".
3. Usala siempre desde ese ícono. Una vez abierta, funciona sin conexión.

## Tus datos

Las series se guardan solo en el dispositivo, sin cuenta. En la pestaña Calendario, abajo, está "Copia de seguridad": sirve para guardar un archivo con todo y para recuperarlo si cambiás de teléfono o borrás la app.

## Créditos

- Fotos de los ejercicios: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), de dominio público.
